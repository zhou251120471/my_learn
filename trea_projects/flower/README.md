# 花草养护记录网站

一个简洁、美观的花草养护记录工具，帮助你轻松管理和追踪植物的养护情况。

## 项目特点

- 🎨 **清新自然的设计**：采用莫兰迪色系配色方案，视觉效果柔和舒适
- 📱 **响应式布局**：适配桌面端和移动端，随时随地记录养护情况
- 💾 **本地数据存储**：数据存储在浏览器本地，无需注册登录
- 🌱 **丰富的植物管理**：支持常见植物选择和自定义添加
- 📅 **直观的养护日历**：查看历史养护记录，了解养护规律
- 📊 **数据统计分析**：掌握近期养护情况，科学管理植物

## 技术栈

- Vue 3 + Vite 5
- Element Plus
- 原生 JavaScript
- LocalStorage 本地存储

## 快速开始

### 环境要求

- Node.js 18+
- npm 9+

### 安装和运行

1. **克隆项目**

```bash
git clone <项目地址>
cd flower
```

2. **安装依赖**

```bash
npm install
```

3. **启动开发服务器**

```bash
npm run dev
```

4. **构建生产版本**

```bash
npm run build
```

## 核心功能使用说明

### 1. 植物选择

- **预设植物**：点击选择常见植物（绿萝、多肉、仙人掌、吊兰、君子兰、芦荟）
- **自定义植物**：在输入框中输入植物名称，点击"添加"按钮
- **上传植物图片**：选择植物后，点击上传区域可添加植物照片

### 2. 养护记录

**三步完成养护记录**：
1. **选择植物**：从植物列表中选择要养护的植物
2. **选择操作**：点击操作按钮（💧 浇水、🌿 施肥、✂️ 修剪）
3. **保存记录**：添加状态描述（可选），上传照片（可选），点击"保存记录"按钮

系统会自动记录当前日期和时间，方便后续查看。

### 3. 养护日历

- **查看记录**：日历中显示有养护记录的日期，点击日期可查看当天详细记录
- **月份切换**：点击左右箭头切换月份，查看不同时期的养护情况
- **记录详情**：展开记录可查看完整信息，包括时间、状态描述和照片

### 4. 数据统计

- **总植物数**：显示所有已添加的植物数量
- **本月浇水**：统计当月浇水次数
- **本月养护**：统计当月所有养护操作次数
- **最近7天**：统计最近一周的养护操作次数
- **最近记录**：显示最近5条养护记录，了解最新养护情况

## 数据存储说明

- **存储位置**：浏览器本地 localStorage
- **数据结构**：养护记录以 JSON 格式存储
- **示例数据**：首次运行时会自动添加两条示例记录，方便了解使用方法
- **数据备份**：建议定期导出备份数据，可通过浏览器开发者工具查看和导出

## 注意事项

- **图片存储**：上传的图片以 Base64 格式存储在本地，大量图片可能会占用较多存储空间
- **浏览器兼容性**：建议使用 Chrome、Firefox、Edge 等现代浏览器
- **数据安全**：本地存储数据仅保存在当前浏览器，清除浏览器数据会导致记录丢失
